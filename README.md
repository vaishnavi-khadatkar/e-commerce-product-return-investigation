## Key Findings

The analysis was performed on 5,000 e-commerce order records.

- **Overall Return Rate:** 29% of the records were marked as returned (1,450 out of 5,000).
- **Highest Return-Rate Category:** Clothing had the highest return rate at 37.43%, with 661 returns out of 1,766 records.
- **Lowest Return-Rate Category:** Books had the lowest return rate at 22.57%, with 172 returns out of 762 records.
- **Most Common Return Reason:** Defective products were the most frequently recorded reason, with 382 returns, followed by Changed Mind (379), Wrong Item (348), and Size Issue (341).
- **Return-Related Cost:** Clothing had the highest total return cost of 132,200, followed by Electronics at 62,800. The recorded average return cost was 200 per returned record across the categories.
- **Shipping Method:** Standard shipping had the highest return rate at 29.41%, while Next-Day shipping had the lowest at 28.50%. The difference was relatively small.
- **Discount Analysis:** Records in the discount range of approximately 25.02–37.38 had a return rate of 32.61%, compared with 25.52% in the lowest discount range. This indicates an association in this dataset, but does not prove that discounts cause returns.
- **Monthly Trend:** May 2024 had the highest monthly return rate at 38.18%. September 2025 had the lowest at 12.50%, but that month contained only 16 records, so the result should be interpreted cautiously.
- **Data Quality:** The dataset contained 5,000 records, with no missing values or exact duplicate rows detected.

## Business Recommendations

- Investigate clothing returns by reviewing product descriptions, size charts, images, and product quality.
- Review defective-product cases to identify possible quality-control issues.
- Examine why higher-discount groups have higher return rates before changing discount policies.
- Monitor return rates and costs by category and shipping method.
- Continue tracking monthly returns and consider the number of records when comparing monthly rates.

These findings describe the supplied dataset and should not be treated as proof of cause and effect.
